
# 🤖 AI Chatbot - Groq API

A friendly AI chatbot built in Python using Groq API.

## How to Run
1. Clone this repo
2. Create a `.env` file and add your key: GROQ_API_KEY=your_key_here
3. Install: pip install groq python-dotenv
4. Run: python Main.py

## Features
- Remembers conversation
- Fast replies with Llama model
- Simple terminal chat
